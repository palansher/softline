#### Как найти медиану?

нужно рассортировать исходный массив по возрастанию.

- Если количество элементов в массиве нечетное

то медиана будет равна среднему элементу, то есть элементу посередине массива.

- Если количество элементов в массиве четное

то находим медиану как среднее арифметическое от двух элементов в центре.

### Типы

#### Usability testing – это тестирование удобства использования интерфейса

Правило четырех кликов: если для доступа к вашему ресурсу клиент будет делать более четырех кликов, то это плохо.

#### функциональное тестирование

#### Unit tests – это тестирование отдельной функции

Это разновидность функциональных тестов.

пишем тестирующую функцию для тестируемой функции. Такие функции начинаются с префикса test.

На вход тестирующиё функции принимаем на один параметр больше, чем в исходной тестируемой функции (+ result).

Эту функцию нужно вызывать несколько раз, например, например для положительных чисел, отрицательных, нулей.

На практике покрывать юнит-тестами нужно 80 и более процентов бизнес-функций.

Сейчас юнит-тесты не пишут руками, а используют фреймворки для написания автотестов.

#### smoke tests

Это поверхностное тестирование. На ранних стадиях разработки.

Например, сделали проект и заходим в него как обычный юзер, не пытаемся ничего сломать, выполняем штатные функции.

Эти тесты простые и безопасные.

#### Sanity testing

санитарные тесты.

Здесь тестируем, как работает функция и какие ресурсы потребляет, например, память. Тестируем также производительность.

#### Regression testing

регресс-тестирование

Направлено на то, чтобы не допустить ошибок текущего функционала после обновления и добавления нового.

Допустим, есть старый проект. Прошел год и добавляется новый функционал.

При этом есть риск, добавляя новое, сломать старое.

### Selenium

для авто-тестов, которые имитируют действия обычного пользователя.

Например, мы хотим, чтобы наша система прошлась по всем ссылкам и составила отчет, какие работают, какие нет.

Это наподобие бота, который ходит по страничкам и выполняет действия за пользователя.
