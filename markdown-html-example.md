# Документация по настройке сервера

Примеры использования допустимой HTML-разметки в Markdown:

```
# MD033/no-inline-html: Разрешаем только те HTML-теги, у которых нет аналогов в Markdown
MD033:
  allowed_elements:
    - br        # Перенос строки в таблицах и списках
    - details   # Раскрывающийся блок (аккордеон/спойлер)
    - summary   # Заголовок раскрывающегося блока
    - sub       # Нижний индекс (например, H₂O)
    - sup       # Верхний индекс (например, X²)
    - kbd       # Оформление комбинаций клавиш (например, <kbd>Ctrl</kbd>+<kbd>C</kbd>)
```

## 1. Сводка по окружениям

| Сервер | Назначение | Статус |
| :--- | :--- | :--- |
| **Production**<br>*(Основной)* | Обслуживание клиентов | `Active` |
| **Staging**<br>*(Тестовый)* | Проверка релизов | `Standby` |

---

## 2. Системные требования

* **Занимаемый объем:** Не менее 500 м<sup>3</sup> в стойке (нагрузка до 10<sup>5</sup> RPS).
* **Охлаждение:** Требуется подача H<sub>2</sub>O для жидкостных систем.

---

## 3. Полезные горячие клавиши

Для быстрого вызова терминала нажмите <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>T</kbd>.
Чтобы сохранить конфиг, используйте <kbd>Ctrl</kbd> + <kbd>S</kbd> (на macOS: <kbd>Cmd</kbd> + <kbd>S</kbd>).
