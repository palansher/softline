## @app.context_processor

Допустим, мы хотим отправить информацию о текущем пользователе в каждый view - на каждую веб-страницу.

Чтобы не использовать для каждой страницы метод рендер, чтобы передавать пользователя в каждую страницу, можно сделать это глобально.

```
@app.context_processor
def inject_user():
    return dict(current_user=get_current_user())
```

current_user - Теперь эту переменную можно использовать в каждом шаблоне страницы.

## Kafka - продолжение

0.58.44

/home/vp/code/learn-python/m3_8_lesson/code/Методичка по Kafka.txt

В Kafka нет термина сообщения. Есть термин событие. Где события – это и есть сообщение.

В Kafka мы манипулируем действиями. Заказ создан, юзер залогинился и так далее.

Консюмер подписывается на топик и сам считывает из него сообщения.

В Kafka данные сохраняются не на одной партиции, а тиражируются на другие сервера на другие партиции.

Главная партиция называется Leader партиция и также есть FileOver партиции ( реплики).
Leader партиция – это основная партиция.

Так Kafka гарантирует доставку сообщений.

Партиция – это неизменяемая последовательность упорядоченных сообщений.
