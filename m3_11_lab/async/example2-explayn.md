# example2.py пояснения кода

Главная цель этого скрипта — **эффективно использовать время ожидания**.

С помощью функции `asyncio.gather()` мы говорим событийному циклу: *«Запусти эти две задачи одновременно и не продолжай выполнение дальше, пока они Обе не завершатся»*.

Жизненный аналог здесь идеален: вместо того чтобы 5 минут просто сидеть и смотреть на часы в ожидании созвона, вы успеваете пообедать за это время.

---

## Пошаговая хронология событий (по миллисекундам)

Вот что происходит «под капотом» с момента запуска программы:

```
[00:00.000] asyncio.run(main()) создаёт Event Loop и запускает main().
 ├─► Вызывается asyncio.gather(wait_call(), dinner()).
 ├─► Event Loop регистрирует обе корутины и передает управление первой — wait_call().
 │
 ├─► [wait_call] Печатает в консоль: "Созвон через 5 минут"
 ├─► [wait_call] Встречает `await asyncio.sleep(5)` — ЗАМИРАЕТ на 5 секунд
 │   и ОТДАЕТ управление обратно в Event Loop.
 │
 ├─► [Event Loop] Переключается на следующую готовую задачу — dinner().
 ├─► [dinner]    Печатает в консоль: "Обед"
 ├─► [dinner]    Завершается полностью.
 │
 ├─► [Event Loop] Ждет оставшиеся ~4.99 секунды (других задач больше нет).
 │
[00:05.000] (Прошло 5 секунд)
 ├─► [wait_call] Просыпается после sleep.
 ├─► [wait_call] Печатает в консоль: "Созвон начался"
 └─► [wait_call] Завершается.

[Event Loop] Обе задачи из gather завершены -> main() завершается -> программа закрывается.

```

---

## Вывод в консоли

Из-за такой асинхронной хронологии вывод в терминале будет следующим:

```text
Созвон через 5 минут
Обед
Созвон начался

```

Обратите внимание: строка **"Обед"** появляется **мгновенно** вслед за строкой **"Созвон через 5 минут"**, а не через 5 секунд после неё!

## В чём разница с обычным кодом?

Если бы мы написали тот же код последовательно (без `gather`):

```python
# Последовательное выполнение:
await wait_call()  # Ждем 5 секунд...
await dinner()  # ...и только ПОТОМ идем обедать

```

Программа работала бы так:

1. Вывела бы: *"Созвон через 5 минут"*
2. Простояла бы в паузе полные 5 секунд.
3. Вывела бы: *"Созвон начался"*
4. И только в самом конце вывела бы: *"Обед"*.

`asyncio.gather()` помог совместить паузу ожидания из первой функции с выполнением полезной работы во второй.
