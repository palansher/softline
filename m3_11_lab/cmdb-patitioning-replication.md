# Памятка: Репликация и Партиционирование

## Репликация

**Репликация** — копирование таблиц и размещение их по разным серверам.


## Партиционирование

**Партиционирование** — это разделение большой таблицы на более мелкие части таблицы, которые логически остаются единой таблицей.

### Когда нужно применять партиционирование

1) Если размер таблицы более 10 ГБ
2) Когда происходят медленные запросы даже при наличии индексов

### Виды партиционирования

1) **RANGE** — по диапазону: `PARTITION BY RANGE(date_sale)`
2) **HASH** — равномерное распределение
3) **LIST** — разбиваем данные по категориям

**ЦЕЛЬ** — создать физически множество мелких таблиц, с которыми можно работать как с единой логической единицей.

---

### Пример №1

Например, таблица с продажами за несколько лет. Можно разбить ее на разные партиции по годам, к примеру.

**Партиционирование по диапазону:**

```sql
CREATE TABLE store_sales(
    id serial,
    sale_date date not null,
    item_id int,
    amount int,
    category varchar(100)
) PARTITION BY RANGE(sale_date);

CREATE TABLE sales_2023 PARTITION OF store_sales
FOR VALUES FROM ('2023-01-01') TO ('2023-12-31');

CREATE TABLE sales_2024 PARTITION OF store_sales
FOR VALUES FROM ('2024-01-01') TO ('2024-12-31');

CREATE TABLE sales_2025 PARTITION OF store_sales
FOR VALUES FROM ('2025-01-01') TO ('2025-12-31');
```
